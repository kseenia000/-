# Random Task Generator (Генератор случайных задач)

## Описание

Данное приложение представляет собой генератор случайных задач с графическим интерфейсом (GUI), созданный с использованием библиотеки `tkinter` в Python. Приложение позволяет:

•   Выбирать тип задачи (учеба, спорт, работа или все).
•   Генерировать случайную задачу на основе выбранного типа.
•   Добавлять свои собственные задачи с указанием типа.
•   Просматривать историю сгенерированных задач.
•   Сохранять историю задач в файл `task_history.json`.

## Инструкция по запуску

1.  **Убедитесь, что у вас установлен Python.** Если нет, скачайте и установите с [python.org](https://www.python.org/).
2.  **Сохраните код:** Скопируйте предоставленный Python код и сохраните его в файл с расширением `.py` (например, `random_task_generator.py`).
3.  **Запустите приложение:** Откройте терминал или командную строку, перейдите в каталог, где сохранен файл, и выполните команду:
bash
  python random_task_generator.py

4. **Используйте приложение:**
  
•  Выберите тип задачи из выпадающего списка или оставьте "все" для случайной задачи из любого типа.
  
•  Нажмите кнопку "Сгенерировать задачу", чтобы получить новую задачу.
  
•  Чтобы добавить свою задачу, введите ее тип и описание в соответствующие поля внизу окна и нажмите "Добавить".
  
•  Нажмите "Показать историю", чтобы увидеть список ранее сгенерированных задач.

 ## Структура проекта

•  random_task_generator.py: Основной файл с кодом приложения.

•  task_history.json: Файл для хранения истории сгенерированных задач (создается автоматически при первом запуске или при сохранении истории).

 ## Функционал

•  Предопределенные задачи: Включены задачи для категорий "учеба", "спорт", "работа".

•  Динамическое добавление задач: Пользователь может добавлять свои типы задач и описания.

•  Фильтрация по типу: Возможность генерировать задачи только определенного типа.

•  История задач: Все сгенерированные задачи сохраняются.

•  Сохранение истории: История задач сохраняется в формате JSON, что позволяет восстановить ее при перезапуске приложения.

•  Корректность ввода: Проверяется, чтобы поля ввода не были пустыми.
