# Простой менеджер списка дел (To-Do List)

## Описание программы

Это консольное приложение на Python, предназначенное для эффективного управления списком дел. Программа позволяет пользователям:

•   **Добавлять новые задачи:** С указанием описания.
•   **Просматривать список дел:** С четким отображением статуса выполнения каждой задачи (выполнено/не выполнено) с помощью символов, имитирующих чекбоксы.
•   **Отмечать задачи как выполненные:** Изменяя их статус.
•   **Удалять задачи:** Для поддержания актуальности списка.

Все данные надежно сохраняются в файле `todo_data.json` в формате JSON, что гарантирует их сохранность между сессиями работы с программой. Интерфейс программы интуитивно понятен и ориентирован на удобство пользователя.

## Требования для запуска

•   **Python:** Версия 3.7 или выше.
•   **Стандартные библиотеки Python:** Программа использует только встроенные модули (`json`, `os`, `sys`), поэтому не требует установки дополнительных пакетов.

 ## Как пользоваться

При запуске программы вы увидите главное меню:
```
Добро пожаловать в ваш личный менеджер списка дел!

--- Главное меню ---
1. 📋 Показать список дел
2. ➕ Добавить новую задачу
3. ✅ Отметить задачу как выполненную
4. 🗑️ Удалить задачу
5. 🚪 Выйти
```
•  1. Показать список дел: Отображает все задачи. Выполненные задачи помечены ✅, невыполненные — ⬜.

•  2. Добавить новую задачу: Программа запросит описание. Введите его и нажмите Enter.

•  3. Отметить задачу как выполненную: Сначала отобразится список дел. Затем введите номер задачи, которую хотите отметить. Можно ввести "отмена" для выхода из этого действия.

•  4. Удалить задачу: Аналогично предыдущему пункту, сначала отображается список, затем вы вводите номер задачи для удаления. Можно ввести "отмена".

•  5. Выйти: Завершает работу программы.

 Архитектура проекта

Проект состоит из следующих файлов:

•  todo_list.py: Основной скрипт программы, содержащий всю логику работы с задачами и пользовательским интерфейсом.

•  todo_data.json: Файл для хранения данных (списка задач) в формате JSON.

•  .gitignore: Файл конфигурации Git, исключающий автоматическое добавление todo_data.json и других временных файлов в репозиторий.
